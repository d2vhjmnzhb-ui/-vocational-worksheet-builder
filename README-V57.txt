V57 — ครูควบคุมการเผยแพร่คะแนน/เกรด และรูปแบบส่งงาน
ต่อจาก V56 โดยรักษาข้อมูลและฟังก์ชันเดิม

1. ซ่อน/เผยแพร่ผล
งานและคะแนน → เลือกห้อง → เผยแพร่คะแนน / ตั้งค่าเกรด
เลือก: ซ่อนคะแนนและเกรด / เผยแพร่คะแนนแต่ซ่อนเกรด / เผยแพร่ทั้งสอง
ค่าเริ่มต้นของห้องเดิมและห้องใหม่คือซ่อนคะแนนและเกรด จนกว่าครูเลือกเผยแพร่
ครูยังเห็นคะแนนและเกรดครบ ตรวจและปรับคะแนนได้ตามเดิม
นักเรียนยังเห็นงานที่ส่ง งานขาด กำหนดส่ง คะแนนเต็ม และสถานะตรวจงาน
เมื่อซ่อน ระบบไม่ส่งคะแนนรายงาน คะแนนรวม เปอร์เซ็นต์ เกรด และ feedback ไปยัง getStudentWork
เมื่อเผยแพร่เฉพาะคะแนน ระบบไม่ส่งเกรดหรือเกณฑ์เกรดไปยัง getStudentWork
การเปลี่ยนมีผลเมื่อหน้านักเรียนโหลดข้อมูลใหม่/กดอัปเดตงาน ไม่สามารถเรียกคืนข้อมูลที่เคยเผยแพร่และผู้ใช้บันทึกไว้แล้ว
การตั้งค่านี้ครอบคลุม student-work.html เท่านั้น ไม่เปลี่ยนการแสดงผลของหน้าสอบ student-exam.html เดิม

2. รูปแบบส่งงาน
งานใหม่มีค่าเริ่มต้น “ส่งไฟล์เท่านั้น”
เลือกได้: ไฟล์ / รูปภาพ / PDF / ข้อความ / ลิงก์ / เลือกวิธีส่งได้
ไฟล์ รูปภาพ และ PDF ไม่มีช่องให้พิมพ์คำตอบหรือส่งลิงก์ และต้องมีไฟล์จริงที่อัปโหลดหรือเก็บจากฉบับเดิม
รูปภาพรับ JPG PNG WebP HEIC HEIF; PDF รับนามสกุล .pdf
ชนิดไฟล์ตรวจจากนามสกุลตามระบบเดิม ไม่ได้วิเคราะห์ว่าเนื้อหาสร้างด้วย AI หรือไม่
ข้อความ/ลิงก์แสดงเฉพาะช่องของประเภทนั้น
ตรวจประเภทฝั่ง backend อีกชั้น ไม่ใช่แค่ซ่อน UI
งานเดิม: ในตารางคะแนน กด “รูปแบบส่งงาน” ใต้ชื่องาน → เลือกรูปแบบ → บันทึก
การเปลี่ยนรูปแบบไม่ลบไฟล์ งาน หรือคะแนนเก่า มีผลต่อการส่งครั้งถัดไป
งานเดิมแบบ submission/worksheet ยังคงเลือกวิธีส่งได้จนกว่าครูเปลี่ยนประเภท

3. ติดตั้ง
GitHub: อัปทับ index.html, teacher-dashboard.js, assignments.js, student-work.html, student-work.js, work-api.js
หรืออัปไฟล์ทั้งชุดทับเดิมโดยไม่ลบข้อมูล
Apps Script: ใช้ Code.gs.txt จาก V57 แทนโค้ดในโปรเจ็กต์ที่ต้องการใช้งาน แล้วบันทึกและ Deploy เวอร์ชันใหม่
จำเป็นต้องอัป Apps Script ด้วย เพราะมีตัวกรองข้อมูลคะแนนและตรวจประเภทงานที่ backend
โปรเจ็กต์เดิมที่ setup แล้วไม่ต้องสร้างกุญแจใหม่
โปรเจ็กต์บัญชีใหม่ที่ setupV56 แล้วใช้ค่าที่สร้างไว้ได้ setupV57 ก็ใช้ค่ากุญแจ/โฟลเดอร์เดิมของโปรเจ็กต์นั้น
เพิ่มคอลัมน์ resultVisibility ต่อท้าย Classes โดยไม่ย้ายหรือลบคอลัมน์เดิม

สำคัญเรื่องย้ายบัญชีที่กำลังทำอยู่:
ยังไม่ได้รับ URL /exec ของบัญชีใหม่ ชุดนี้จึงยังเก็บ URL ระบบเดิม ไม่ได้เปลี่ยนบัญชีให้แล้ว
ต้องนำ URL /exec ใหม่มาเชื่อมในไฟล์เว็บก่อนใช้บัญชีใหม่จริง
เก็บ Google Sheet เดิมที่แชร์ให้บัญชีใหม่ไว้ ไม่ต้องลบคะแนนหรือห้อง
V57 ไม่ได้แก้โควตา Drive โดยตรง การเปลี่ยนบัญชีต้องดำเนินการต่อให้ครบ
