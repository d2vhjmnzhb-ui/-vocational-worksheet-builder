V50 – Scroll Safe Exam Guard

แก้ปัญหาเลื่อนหน้าจอแล้วระบบส่งข้อสอบเอง

- risk=warn จะไม่มีสิทธิ์ส่งข้อสอบอัตโนมัติจากเหตุการณ์เสี่ยง ไม่ว่ากรณีใด
- การเลื่อนหน้า/แถบ URL มือถือยุบ-ขยาย ไม่ถูกใช้เป็นเหตุผล Split Screen
- Split Screen ต้องหดความกว้างชัดเจน หรือพื้นที่หดทั้งกว้างและสูง และค้าง 4 วินาที
- baseline ใช้ขนาด viewport สูงสุดที่เคยเห็น ลด false positive จาก browser chrome
- Auto submit จากความเสี่ยงทำงานเฉพาะลิงก์ risk=submit เท่านั้น
- หมดเวลายังส่งอัตโนมัติตามปกติ
- ลิงก์ที่เผยแพร่ใหม่เพิ่ม v=50 เพื่อลดปัญหา cache เก่า

Apps Script: ใช้ตัวเดิมจาก V49 ได้ ไม่ต้อง Deploy ใหม่ หาก V49 API ใช้งานอยู่แล้ว
