เกมครูเจต V33 + เว็บข้อสอบ V53

สิ่งที่เพิ่ม
- หน้า moto-game.html กรอกชื่อจริงและนามสกุลก่อนแข่ง
- คะแนนเกมรวมทุกเครื่อง เก็บในชีต GameAttempts ภายในไฟล์ Google Sheets เดิม
- เรียงอันดับตามข้อถูกมากที่สุด แล้วเวลารวมน้อยที่สุด (เวลารวมช่วงพักด้วย)
- หนึ่งชื่อเต็มแสดงผลงานดีที่สุด หากชื่อเหมือนกันจะรวมเป็นคนเดียวกัน
- คะแนนเกมแยกจากคะแนนสอบ ใช้คำถามกฎโอห์ม 20 ข้อของเกม ยังไม่ดึงชุดข้อสอบที่เผยแพร่มาเล่น
- ปุ่มเข้าเกมบนหน้าเว็บหลัก ปุ่มกลับหน้าเว็บข้อสอบในเกม
- ไม่บันทึกอันดับในโหมดฝึกซ้อม
- คงภาพคอที่แก้แล้ว เสียง และคำตอบข้อ 7 ข. 3 A

เปิดใช้งาน (ต้องทำทั้งสองส่วน)
1. อัปโหลดไฟล์ทั้งหมดใน ZIP นี้แทนไฟล์บน repository เว็บใบงาน/ข้อสอบเดิม โดยวาง index.html และ moto-game.html ในระดับเดียวกัน
2. เปิด Apps Script ของระบบข้อสอบเดิม สำรองโค้ดเดิม แล้วแทน Code.gs ด้วยเนื้อหา Code.gs.txt ใน ZIP นี้
3. กดบันทึก > Deploy (ทำให้ใช้งานได้) > Manage deployments (จัดการการทำให้ใช้งานได้) > รูปดินสอ > New version (เวอร์ชันใหม่) > Deploy
   ใช้ deployment เดิมเพื่อคง URL เดิม ตั้งให้ทำงานเป็นเจ้าของและเข้าถึงได้สำหรับผู้ใช้เว็บเดิม
4. เปิดหน้าเว็บหลักแล้วกด “เกมมอเตอร์ไซค์ครูเจต” ลงทะเบียน เล่นจบ แล้วตรวจอันดับจากมือถืออีกเครื่อง

ถ้าขึ้นระบบยังไม่ได้อัปเดต Apps Script: ยังไม่ได้ทำข้อ 2–3 หรืออัปเดตคนละ deployment
ถ้าส่งคะแนนไม่ได้: กด “ส่งคะแนนอีกครั้ง” โดยอย่าปิดหน้าเกมก่อนบันทึกสำเร็จ
อันดับนี้ใช้ฝึกเรียน ไม่มีระบบยืนยันตัวบุคคล ชื่อสามารถกรอกเองได้
คะแนนสนามที่แสดงระหว่างแข่งเป็นคะแนนโบนัส ส่วนอันดับรวมใช้จำนวนข้อถูกที่ตรวจจากเซิร์ฟเวอร์

ตรวจแล้ว: การตรวจคำตอบฝั่งเซิร์ฟเวอร์ ข้อ 7 การเรียงอันดับ การส่งซ้ำ และการเชื่อมเหตุการณ์เกม
ยังไม่ได้อัปเดตเว็บไซต์หรือ Apps Script จริง และยังไม่ได้ทดสอบบน Safari ของ iPhone จริง
