V59 — ตารางรวมสมุดคะแนน
เปิด งานและคะแนน → เลือกห้อง → ตรวจงาน / คะแนนรวม / เกรด → ตารางรวม
เลือก ตารางรวม / รายคน ได้ทุกขนาดหน้าจอ และจำมุมมองไว้ในเครื่อง
ค้นหาชื่อหรือรหัสนักเรียนได้ทันที ใช้ร่วมกับตัวกรองงานขาด/รอตรวจ
ตารางเลื่อนซ้ายขวาและขึ้นลงได้ ตรึงชื่อนักเรียนและหัวตาราง
สีหัวคอลัมน์: ใบงานน้ำเงิน แบบทดสอบม่วง ปฏิบัติเขียว อื่น ๆ ทอง
ถ้าใช้คะแนนแบ่งหมวด แสดงคะแนนสรุป4หมวดก่อนคอลัมน์งาน
งานเรียงตามหมวด; แต่ละช่องแสดงคะแนนและสถานะพร้อมสี ไม่ใช้สีอย่างเดียว
แตะช่องงานเพื่อตรวจ/ให้คะแนน แตะชื่อเพื่อดูงานทั้งหมดของคนเดียว
รูปแบบตารางมุมเหลี่ยมเล็กน้อย ไม่มีกราฟวงกลม
ดาวน์โหลด CSV ใช้ปุ่มเดิม

index.html
teacher-dashboard.js
assignments.js
