Vocational Learning Studio — V55 งาน / ส่งไฟล์ / สมุดคะแนน
พัฒนาจาก ZIP V54 ที่ผู้ใช้แนบโดยตรง ไม่สร้างโครงการใหม่

ติดตั้ง (ต้อง Deploy Apps Script ใหม่)
1. สำรอง Google Sheet และโค้ด Apps Script เดิมไว้ก่อนอัปเดต
2. เปิดโครงการ Apps Script เดิม แทนเนื้อหา Code.gs ด้วย Code.gs.txt ใน ZIP นี้
   คง SS_ID เดิมตามข้อมูลของคุณ โค้ดชุดนี้ใช้ SS_ID เดียวกับ V54 ที่แนบ
3. เลือกฟังก์ชัน setupV55 แล้วกด Run หนึ่งครั้ง ยอมรับสิทธิ์ Spreadsheet และ Drive
   ฟังก์ชันนี้เพิ่มคอลัมน์ท้ายตารางเดิม สร้าง WorkRequests สร้างโฟลเดอร์ Drive ส่วนตัว
   และเพิ่มรหัสเข้าดูงานในรายชื่อเดิม ไม่ลบคะแนนหรือข้อสอบเดิม
   อ่าน Teacher key จาก Execution log เก็บเป็นความลับ ไม่ใส่ลง GitHub
   รัน setupV55 ซ้ำได้ รหัสเดิมจะยังอยู่
4. Deploy > Manage deployments > Edit > New version > Deploy
   ใช้ deployment เดิมเพื่อคง URL /exec เดิม Execute as: Me
   ผู้เข้าถึง Web app ต้องรวมผู้เรียนที่ไม่มีบัญชี Google (Anyone หากนโยบายบัญชีอนุญาต)
   ถ้าสร้าง deployment ใหม่ ให้เปลี่ยน URL ใน work-api.js, exam-publish.js และ student-exam.html ให้ตรงกัน
5. อัปโหลดไฟล์เว็บด้านล่างทับใน repository GitHub Pages เดิม:
   index.html
   teacher-dashboard.js
   assignments.js
   assignments.css
   student-work.html
   student-work.js (ใหม่)
   student-work.css (ใหม่)
   work-api.js (ใหม่)
   qrcode.min.js (ใหม่)
   THIRD-PARTY-LICENSES.txt (ใหม่)
   ไฟล์เว็บเดิมอื่น ๆ คงไว้ทั้งหมด ZIP นี้มีไฟล์เดิมครบ
   Code.gs.txt ใช้กับ Apps Script ไม่ใช่ไฟล์รันบน GitHub Pages
6. เปิดหน้าเว็บใหม่ เมนู งานและคะแนน วาง Teacher key แล้วกดเชื่อมต่อ
   กุญแจเก็บใน sessionStorage เฉพาะแท็บ ไม่ฝังในลิงก์นักเรียน
7. สร้างห้อง/รายชื่อ หรือเลือกห้องเดิม เปิด “รายชื่อ / รหัสเข้าเรียน”
   แจกรหัสเข้าดูงานให้เจ้าของรหัสเป็นรายคน ห้ามแจกทั้งตารางให้ทั้งห้อง
8. เปิด QR ห้องเรียนให้นักเรียนสแกน นักเรียนกรอกรหัสนักเรียน + รหัสเข้าดูงาน

สิ่งที่เพิ่มและแก้
- แก้เมนูงาน V54 ไม่เปิด pane และไม่ซ่อน workspace เดิม
- สร้างห้องด้วยแบบฟอร์มหลายบรรทัด ตรวจรหัสซ้ำ แก้ชื่อและเพิ่มรายชื่อได้
- สร้างงานทั่วไป/ใบงาน/ข้อความ/ลิงก์/ไฟล์/ข้อสอบ ชื่อใบงานและคำชี้แจงแยกช่อง
- QR สร้างภายในเบราว์เซอร์ด้วยไลบรารีใน ZIP ไม่ส่งลิงก์ไปบริการ QR ภายนอก
- ส่งรูป JPG/PNG/WebP, PDF, DOCX, XLSX, PPTX, TXT
  สูงสุด 3 ไฟล์ต่อหนึ่งงาน ไฟล์ละ 3 MiB รวม 6 MiB (รวมไฟล์เดิมที่เก็บไว้)
  ภาพ HEIC ต้องแปลงเป็น JPG/PNG หรือเลือกถ่ายรูปแบบ Most Compatible
- รูปที่เลือกมี preview ก่อนส่ง ไฟล์เก็บใน Drive ของบัญชีที่ Deploy แบบส่วนตัว
  ครูต้องเปิดไฟล์ด้วยบัญชี Google เจ้าของ Apps Script; นักเรียนเห็นชื่อไฟล์ที่ส่งแล้ว
  ระบบไม่เปิดไฟล์แนบแบบ Anyone with the link
- ยืนยันการเขียนด้วย requestId + WorkRequests + receipt; ไม่ถือว่า opaque fetch สำเร็จคือบันทึกสำเร็จ
- Lock ป้องกันแก้ไขชนกัน, requestId ลดการเขียนซ้ำ, revision กันตรวจงานฉบับเก่า
- ส่งฉบับแก้ไขล้างคะแนน/feedback ของงานนั้นให้ครูตรวจใหม่ พร้อมข้อความเตือนก่อนส่ง
  ไฟล์เดิมที่ไม่เลือกเก็บยังอยู่แบบส่วนตัวใน Drive ไม่ลบหลักฐานอัตโนมัติ
- ครูแตะชื่อ/ช่องคะแนนเพื่ออ่านคำตอบ เปิดลิงก์และไฟล์ แล้วให้คะแนน/feedback ในหน้าสมุดคะแนน
- Dashboard จำนวนงานขาด/รอตรวจ ค่าเฉลี่ย % ตัวกรอง และส่งออก CSV ภาษาไทย
- นักเรียนเห็นเฉพาะงานตนเอง มีตัวกรองงานยังไม่ส่ง รอตรวจ ตรวจแล้ว
- คะแนนข้อสอบจับคู่รหัสนักเรียนตรงกัน ใช้ครั้ง SUBMITTED ล่าสุดตามวันเวลาส่ง
  ปรับคะแนน: คะแนนข้อสอบ / คะแนนเต็มข้อสอบ × คะแนนเต็มงาน
  รักษาคะแนน 0; แสดงรอตรวจข้อเขียนเมื่อคะแนนยังไม่สมบูรณ์
- getLiveResults เดิมอ่านเพียง 16 คอลัมน์แต่ใช้คอลัมน์ 17–18: แก้ให้อ่านครบ เหตุการณ์ล่าสุดจึงไม่หาย
- ไม่แก้ student-exam.html, AI Import, Slide Studio, PDF/PPTX และโครงสร้าง IndexedDB เดิม
- แคช dashboard ในหน้า 20 วินาที; refresh 45 วินาทีเฉพาะหน้าเปิดและไม่กำลังตรวจ/แก้ไข
  ไม่มีคำขอ dashboard ซ้อนกัน และไม่โหลดข้อมูลห้องก่อนครูเชื่อมต่อ

ข้อมูลเดิม / API
- localStorage v54class และ swid ยังใช้ได้; key เดิมของใบงาน สไลด์ และข้อสอบคงเดิม
- Classes: ใช้ studentsJson เดิม เพิ่ม accessCode ในแต่ละคน
- Works: เพิ่ม description, worksheetName ท้ายคอลัมน์เดิม
- Submissions: เพิ่ม attachmentsJson, revision ท้ายคอลัมน์เดิม
- ชื่อ actions เดิมยังอยู่ แต่ API งานครูต้องส่ง teacherKey;
  getStudentWork/submitWork ต้องส่ง accessCode; งานเขียนต้องส่ง requestId
  จึงต้องอัปเว็บและ backend V55 คู่กัน หน้า V54 เก่าต้อง refresh
- createClass/createWork/submitWork/saveWorkGrade/updateRoster ใช้ POST เท่านั้น
- GET งานครูส่ง key ผ่าน JSONP เพื่อเข้ากับ GitHub Pages เดิม อย่าแชร์ URL request ที่มีกุญแจ

ขอบเขตที่ยังมี
- การป้องกันด้วยกุญแจครูครอบคลุมระบบงานและคะแนนใหม่เท่านั้น
  API ข้อสอบเดิมยังคงรูปแบบสิทธิ์ของ V54; ยังไม่ใช่ระบบล็อกอินครูทั้งเว็บไซต์
- ยังไม่รองรับแบ่งน้ำหนักหมวดคะแนน 30/20/30/20 รวม 100; ปัจจุบันรวมคะแนนเต็มทุกงานและคิด %
- ประเภทใบงานบันทึกชื่อ/คำชี้แจง ครูยังต้องแจก PDF หรือลิงก์ใบงาน ไม่ได้แนบ worksheet ที่สร้างโดยอัตโนมัติ
- ยังไม่มีลบงาน/ลบรายชื่อ/แก้คะแนนเต็มงานหลังเผยแพร่ เพื่อไม่เปลี่ยนข้อมูลคะแนนเดิมโดยไม่ตั้งใจ
- backend ยังอ่านข้อมูลจาก Sheet ต่อคำขอ ไม่มีฐานข้อมูลแยกรายห้อง
  ลดคำขอและจัด index ภายในหนึ่งคำขอ แต่ยังไม่เหมาะกับข้อมูลขนาดใหญ่มาก
- Drive/Apps Script ยังขึ้นกับ quota และสิทธิ์ของบัญชีครู
- รายละเอียดผลทดสอบอยู่ใน TEST-REPORT-V55.txt ไม่ได้ทดสอบกับ Sheet/Drive จริงของผู้ใช้
