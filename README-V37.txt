Vocational Worksheet Builder V37 – Full UI Refresh + Editable Slide Studio

อัปเดตหลัก
- ปรับหน้าตาเว็บครูใหม่ทั้งระบบให้เป็น Vocational Learning Studio โทนมืออาชีพ
- เมนูหลัก 4 ช่อง: สร้างใบงาน / ข้อสอบออนไลน์ / สร้างสไลด์ / ผลการสอบ
- Slide Studio ใช้แนว Industrial Editorial จากภาพอ้างอิงของผู้ใช้ (ไม่คัดลอกภาพต้นฉบับ)
- เลือกขนาดตัวอักษรหัวข้อและเนื้อหาได้แบบสไลเดอร์
- คลิกช่อง “เพิ่มภาพประกอบ” บนสไลด์เพื่อเลือกรูปจาก iPad/คอมได้โดยตรง
- เมื่อมีรูปแล้ว คลิกที่รูป/พื้นหลังเพื่อเปลี่ยนรูปได้
- ภาพถูกครอบแบบ cover และมี Gradient/Fade Overlay ปรับความเข้มและทิศทางได้
- เลือกการวางภาพ 3 แบบ: Editorial เต็มพื้นหลัง, Split ด้านขวา, Panel ในกรอบ
- ยังคงค้น Google Images / เปิด AI เพื่อสร้างภาพ / อัปโหลดรูปเอง
- คงระบบเดิมของใบงาน ข้อสอบออนไลน์ ผลสอบ และการส่งออก PDF/PPTX
