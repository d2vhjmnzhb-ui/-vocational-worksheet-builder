V36 Pro Slide Studio
- หน้าตา Slide Studio ปรับใหม่ตามแนว mockup: thumbnails ซ้าย, editor กลาง, tools ขวา
- เพิ่ม/เปลี่ยน/ลบภาพต่อสไลด์ได้จาก iPad และคอม
- รูปภาพใช้เป็นพื้นหลังแบบ cover และมี gradient/fade overlay อัตโนมัติ ไม่วางภาพดิบทับข้อความ
- ปรับความเข้มของ fade 0-100% และทิศทาง ซ้าย/ขวา/บน/ล่าง
- ปุ่มค้น Google Images เปิดผลค้นภาพตามวิชา+หัวข้อ+ชื่อสไลด์
- ปุ่ม AI สร้างภาพ คัดลอก prompt และเปิด ChatGPT; การสร้างภาพในเว็บโดยตรงต้องต่อ API backend เพิ่ม
- สไตล์ 4 แบบ Modern Blue / Dark Tech / Warm Classroom / Minimal Clean
- PDF 16:9 และ PowerPoint; PowerPoint ฝังภาพที่อัปโหลดเมื่อเป็น data URL
- ระบบใบงาน ข้อสอบออนไลน์ และผลสอบเดิมคงอยู่
