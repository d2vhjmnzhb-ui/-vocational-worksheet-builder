V45 - Published Exam Manager

เพิ่ม:
- หน้า "ข้อสอบที่เผยแพร่แล้ว"
- แสดงสถานะ เปิดใช้งาน / ปิดรับคำตอบ
- ปิดรับคำตอบ โดยเก็บผลสอบเดิมไว้
- เปิดข้อสอบกลับมาใหม่
- ดูผลสอบจากรายการ
- ลบถาวร พร้อมลบ Attempts และ Events ของชุดนั้น
- รายการแสดงจำนวนข้อ เวลา ผู้เข้าสอบ และวันที่เผยแพร่

สำคัญ: V45 ต้องอัปเดตทั้งเว็บบน GitHub Pages และ Google Apps Script
1) เปิด Apps Script ที่ใช้กับระบบข้อสอบ
2) เปิดไฟล์ Code.gs
3) แทนโค้ดเดิมทั้งหมดด้วย Code.gs.txt จากชุด V45
4) Deploy > Manage deployments > Edit > New version > Deploy
5) URL Web App เดิมควรใช้งานต่อได้ ถ้า Deployment เดิมตั้ง Execute as Me และ Who has access ตามที่ใช้อยู่
6) อัปไฟล์เว็บ V45 ขึ้น GitHub Pages

หมายเหตุ:
- "ปิดรับคำตอบ" = ลิงก์ข้อสอบเดิมจะเริ่มสอบใหม่ไม่ได้ แต่คะแนนเดิมยังอยู่
- "ลบถาวร" = ลบข้อสอบ + ผลสอบ + event logs ของข้อสอบนั้น และย้อนกลับจากหน้าเว็บไม่ได้
