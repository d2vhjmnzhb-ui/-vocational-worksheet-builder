V64 — Faster classroom loading

ต้องอัปเดตทั้ง Apps Script และไฟล์เว็บ
1. แทนโค้ดในโปรเจกต์ Apps Script เดิมด้วย Code.gs.txt นี้ แล้วบันทึก
2. การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ดินสอ > เวอร์ชันใหม่ > ทำให้ใช้งานได้
3. ใช้ URL และกุญแจครูเดิม ไม่ต้องลบข้อมูลหรือสร้างโปรเจกต์ใหม่
4. อัปโหลดไฟล์เว็บจาก ZIP ทับ GitHub รวมโฟลเดอร์ vendor (คงจาก V63)

ไฟล์เว็บที่เปลี่ยนจาก V63:
index.html
assignments.js
teacher-dashboard.js
work-api.js
student-work.html
student-work.js
slide-builder.js
pdf-fix.js
Code.gs.txt ต้องนำไปใช้ใน Apps Script ไม่ใช่แค่อัป GitHub

สิ่งที่ปรับ:
- เปิดห้องเดิม: bootstrap รวมรายชื่อห้องและตารางคะแนนในคำขอเดียว
- ตารางครูไม่ส่งคำตอบและไฟล์แนบทั้งห้องมาด้วย โหลดเมื่อกดตรวจรายบุคคล
- เด็กที่จำรหัสไว้หรือลิงก์ส่วนตัวเข้าหน้างานตรงด้วยคำขอเดียว
- แต่ละ doGet เปิด Spreadsheet ครั้งเดียวและอ่านแต่ละชีตครั้งเดียว ใช้ซ้ำเฉพาะคำขอนั้น
- ไม่ใช้ cache คะแนนข้ามคำขอ จึงไม่เพิ่มความเสี่ยงคะแนนเก่าหรือสถานะรับงานค้าง
- ตารางไม่สร้าง DOM ซ้ำเมื่อ live update ได้ข้อมูลเหมือนเดิมและไม่ได้เปิดตรวจงาน
- โหลดเครื่องมือ PDF/PowerPoint เมื่อส่งออกเท่านั้น มี timeout และลองใหม่ได้

ข้อจำกัด:
ยังต้องอ่านชุดข้อมูลของชีตเพื่อกรองห้อง แต่ตัดการอ่านซ้ำภายในคำขอแล้ว
ไม่สามารถรับประกันความเร็วเครือข่ายและเวลารอเริ่มทำงานของ Google Apps Script
ทดสอบด้วย backend จำลอง ไม่ได้ทดสอบบน iPad จริงหรือวัดความเร็วหลัง Deploy
