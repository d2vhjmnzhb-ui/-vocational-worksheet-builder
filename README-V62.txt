V62 — งานล่าสุดและเปิด/ปิดรับงาน
นักเรียน: งานล่าสุด 3 งานเรียงวันที่สั่งใหม่สุด อยู่เหนือตาราง กดดูงานเพื่อเปิดรายละเอียด
ครู: งานและคะแนน > เลือกห้อง > งานที่สั่ง > เลือกงาน > ปิดรับงาน / เปิดรับงานอีกครั้ง
ปิดรับแล้วงานเดิมยังดูได้ คะแนนและไฟล์เดิมคงอยู่ แต่ส่งใหม่/แก้ไขไม่ได้ ตรวจจาก backend ภายใต้ lock เดิม
งานเดิมที่ไม่มีคอลัมน์ accepting ถือว่าเปิดรับโดยอัตโนมัติ
ข้อสอบออนไลน์ใช้การเปิด/ปิดในหน้าข้อสอบที่เผยแพร่แล้ว ไม่ได้ใช้ปุ่มปิดรับงานทั่วไป

ต้อง Deploy Apps Script ใหม่:
1. ใช้โปรเจกต์ Apps Script เดิม แทนโค้ดด้วย Code.gs.txt จาก ZIP นี้ แล้วบันทึก
2. การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (ดินสอ) > เวอร์ชันใหม่ > ทำให้ใช้งานได้
3. ใช้ URL /exec เดิมและกุญแจครูเดิม ไม่ต้องสร้างโปรเจกต์หรือกุญแจใหม่
คอลัมน์ใหม่ถูกเพิ่มอัตโนมัติ ไม่มีการลบชีตหรือคะแนน
