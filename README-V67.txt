V67 — ปรับประสิทธิภาพระบบเดิม ไม่ย้ายฐานข้อมูล
ใช้ GitHub Pages / Apps Script / Google Sheets เดิม

ปรับ:
- รอผลยืนยันการบันทึกได้ถึง 20 วินาทีต่อคำขอ ภายในวงรอรวมเดิม 55 วินาที (เดิมต่อครั้ง 6 วินาที)
- รวมคำขออ่านข้อมูลที่เหมือนกันและกำลังรออยู่ ไม่ยิงซ้ำ
- ชีตใหญ่สแกนคอลัมน์รหัสก่อน อ่านเต็มเฉพาะกลุ่มแถวที่เกี่ยวข้อง หากกระจัดกระจายหรือจำนวนมากใช้ bulk read
- ชีตเล็กอ่านรวดเดียว ไม่แตกคำขอ
- ลดโหลด dashboard ซ้ำหลังสร้างห้อง
- ค้นหานักเรียนรอจังหวะพิมพ์ 180ms ก่อนวาดตารางใหม่
คงฟอร์มเปิดพิมพ์ได้ก่อนโหลดห้อง งานครูกรอกคะแนน งานล่าสุด ปิด/เปิดรับ ภาพผู้ปกครอง และสิทธิ์ซ่อนคะแนน

ต้องอัปเดต Apps Script:
แทนโค้ดโปรเจกต์เดิมด้วย Code.gs.txt > บันทึก > จัดการการทำให้ใช้งานได้ > ดินสอ > เวอร์ชันใหม่ > ทำให้ใช้งานได้
ใช้กุญแจและ URL เดิม ไม่ลบข้อมูล
