V42 Responsive Tablet Editor

ปรับจาก V41 FIX ให้ Slide Studio ใช้งานได้ทั้ง iPad แนวตั้งและแนวนอน:
- แถบเมนูบนไม่ตกบรรทัด/ไม่หลบจอ ใช้เลื่อนแนวนอนเมื่อพื้นที่ไม่พอ
- แนวนอน: คง 3 คอลัมน์ แต่ย่อแถบซ้าย/ขวาเพื่อขยายสไลด์
- แนวตั้ง: สไลด์อยู่ด้านบนเต็มความกว้าง รายการสไลด์เป็นแถบแนวนอน และเครื่องมืออยู่ด้านล่าง
- เพิ่มปุ่ม "ขยายพื้นที่" ซ่อนแถบซ้าย/ขวาชั่วคราวเพื่อดู/แก้สไลด์ใหญ่ขึ้น
- ปรับ touch target สำหรับ iPad และมือถือ
- แก้แท็บเครื่องมือเป็น 4 ช่องไม่ล้น
- ระบบเดิม V41 ยังอยู่ครบ
