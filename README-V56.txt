V56 — สั่งงานง่าย / ส่งงานง่าย / เห็นเกรดชัด
ปรับต่อจาก V55 เดิม รักษาไฟล์ข้อสอบและระบบใบงาน/สไลด์ไว้

ใช้งานหลังติดตั้ง
ครู: งานและคะแนน → เลือกห้อง → + สั่งงาน → ชื่องาน + คะแนนเต็ม → สั่งงานให้นักเรียน
     คำชี้แจง/กำหนดส่งเป็นข้อมูลเสริม งานทุกชนิดส่งรูป ไฟล์ ข้อความ หรือลิงก์ได้
นักเรียน: เปิดลิงก์ห้อง → ใส่รหัสนักเรียนครั้งแรก → เลือกไฟล์/พิมพ์คำตอบ → ส่งงานให้ครู
     ไม่ต้องรหัสเข้าดูงานเพิ่ม หากติ๊กจำฉัน เปิดครั้งถัดไปเข้าได้เลย
ครูตรวจ: กด “ตรวจงาน / คะแนนรวม / เกรด” → แตะชื่อหรือช่องงาน → ใส่คะแนน → บันทึก
     คะแนนรวม คิดเต็ม 100 และเกรดอยู่ข้างชื่อทันที ไม่ต้องส่งออก CSV เพื่อรวมเอง

คะแนนและเกรดอยู่ตรงไหน
งานและคะแนน → เลือกห้อง → ตรวจงาน / คะแนนรวม / เกรด
รวมคะแนนแต่ละงานกับคะแนนข้อสอบที่เชื่อมไว้
คะแนนเต็ม 100 = คะแนนที่ได้รวม ÷ คะแนนเต็มรวม × 100
เกรดเริ่มต้น: 80=4, 75=3.5, 70=3, 65=2.5, 60=2, 55=1.5, 50=1, ต่ำกว่า50=0
นี่เป็นค่าเริ่มต้นในโปรแกรม ปรับให้ตรงเกณฑ์ของครูได้ที่ “เกณฑ์เกรด / การเข้าเรียน”
ถ้ามีงานขาด/รอตรวจ เกรดมี * และเป็นผลคำนวณระหว่างเรียน ไม่ใช่ผลอนุมัติสุดท้าย
ระบบไม่ตัดสินสถานะ มส. จากเวลาเรียนหรือสิทธิ์สอบ
ยังไม่ได้กำหนดน้ำหนักหมวด 30/20/30/20; น้ำหนักมาจากคะแนนเต็มของแต่ละงาน
เช่นต้องการเต็ม 100 ให้คะแนนเต็มงานและข้อสอบรวมเป็น 100 หรือใช้คอลัมน์เต็ม 100 ที่แปลงให้

วิธีเข้าเรียน 2 แบบ
1. แบบง่าย (ค่าเริ่มต้น รวมถึงห้องเก่าที่ไม่ได้ตั้งค่า): รหัสนักเรียนอย่างเดียว + จำเครื่อง
   ผู้ที่รู้รหัสนักเรียนคนอื่นอาจเข้าแทนได้ จึงใช้สำหรับห้องที่ยอมรับการยืนยันแบบนี้
2. ลิงก์ส่วนตัว: เลือกใน “เกณฑ์เกรด / การเข้าเรียน” แล้วเปิด “รายชื่อนักเรียน”
   กดคัดลอกลิงก์ของแต่ละคน ส่งให้เฉพาะเจ้าของลิงก์
   นักเรียนกดแล้วเข้าได้ทันที ไม่ต้องพิมพ์รหัสใด ๆ
   ห้ามเผยแพร่ลิงก์รายคนทั้งห้อง เพราะผู้ถือลิงก์เข้าบัญชีของเจ้าของลิงก์ได้
ทั้งสองแบบ หน้านักเรียนไม่แสดงรายชื่อ/คะแนนของเพื่อนหรือเครื่องมือครู
เครื่องที่ใช้ร่วมกันไม่ควรติ๊กจำฉัน และควรกดเปลี่ยนผู้ใช้เมื่อเสร็จ

   ใช้เฉพาะเครื่องส่วนตัว กดออกจากระบบงานเพื่อล้างกุญแจที่จำไว้

แก้ปัญหาปุ่มส่งแล้วไม่ไป
- ไม่ให้ HTML validation ของช่อง URL หยุดการส่งเงียบ ๆ
- ลิงก์ที่ลืม https:// เช่น drive.google.com/... เติมให้ก่อนตรวจ
- ข้อผิดพลาดและสถานะอยู่ตรงปุ่มส่ง และเลื่อนให้เห็นเมื่อส่งไม่ได้
- ตรวจ backend version ก่อน POST ถ้ายังเก่าบอกให้ Deploy ไม่รอ receipt ที่ไม่มี
- รอผลยืนยันพร้อมการส่ง จำกัดช่วง POST+receipt ประมาณ 55 วินาที
  มีการตรวจเวอร์ชันก่อนหน้าเพิ่มได้สูงสุด 15 วินาที
- ระหว่างส่งแสดงสถานะ ป้องกันการกดซ้ำ และคงไฟล์/คำตอบเมื่อเกิดข้อผิดพลาด
- requestId ลดส่งซ้ำด้วยข้อมูลเดิมในหน้าเดิม; ยังตรวจ revision กันเขียนทับฉบับล่าสุด
- JPG/PNG/WebP ใหญ่กว่า 800 KB จะพยายามย่อด้านยาว 1800 พิกเซลและบีบเป็น JPEG
  หากไฟล์ย่อใหญ่กว่าเดิมใช้ต้นฉบับ อ่านไม่ได้ใช้ต้นฉบับแล้วตรวจขนาด
- รองรับ HEIC/HEIF เป็นไฟล์แนบ แต่ไม่รับประกัน preview ในทุกเบราว์เซอร์
  ไฟล์ละไม่เกิน 3 MiB รวม 6 MiB ไม่เกิน 3 ไฟล์
- Code.gs.txt เปลี่ยนข้อความไทยใน source เป็น Unicode escape (\u0e...)
  เพื่อเลี่ยงการเปิด TXT ผิด encoding บน iPad แล้วคัดลอกตัวเพี้ยนแบบที่พบในภาพ
  เมื่อรัน JavaScript จะได้ภาษาไทยตามเดิม ไม่ต้องแก้ \u ด้วยตนเอง
