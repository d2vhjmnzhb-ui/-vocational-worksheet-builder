V58 — หมวดคะแนนอัตโนมัติ / หน้าคะแนนอ่านง่าย / งานขาดของนักเรียน
พัฒนาต่อจาก V57-FIX1 ใช้ URL Apps Script บัญชีใหม่เดิม

เริ่มใช้แบบสั้น
1. ห้องใหม่ใช้หมวด 30/20/30/20 ให้เลย ไม่ต้องหารคะแนนเอง
2. ห้องเก่า: งานและคะแนน → เลือกห้อง → ตั้งค่าหมวดคะแนน → แบ่งหมวดอัตโนมัติ → บันทึก
   คงวิธีรวมเดิมให้ห้องเก่าจนกว่าครูเลือกเปลี่ยน เพื่อไม่เปลี่ยนคะแนนเดิมโดยไม่ตั้งใจ
3. ตอนสั่งงาน เลือกหมวดได้ทันที ค่าเริ่มต้นใบงาน; เมื่อเลือกข้อสอบออนไลน์ระบบเลือกแบบทดสอบให้
4. งานเก่าอยู่หมวดใบงาน ข้อสอบเก่าอยู่หมวดแบบทดสอบ กดการ์ดใน “งานที่สั่ง” เพื่อเปลี่ยนหมวด/วิธีส่ง/คำชี้แจง

หลักการคะแนน
ใบงาน 30 / แบบทดสอบ 20 / ปฏิบัติ 30 / จิตพิสัยหรืออื่น ๆ 20
คะแนนแต่ละหมวด = คะแนนที่ได้รวมในหมวด ÷ คะแนนเต็มรวมในหมวด × น้ำหนักหมวด
รวมคะแนนหมวดได้คะแนนตัดเกรดเต็ม 100 ใช้เกณฑ์เกรดของห้องเดิม
เช่นใบงานได้96/120 คิดเป็น24/30 ไม่ต้องลดคะแนนงานทีละชิ้น
แก้น้ำหนักครั้งเดียวต่อห้อง น้ำหนักต้องรวม100 หมวดที่ไม่ใช้ตั้ง0และกระจายส่วนที่เหลือได้
หมวดน้ำหนักมากกว่า0แต่ยังไม่มีงานคิด0 ไม่เฉลี่ยเพิ่มให้หมวดอื่น และแสดงเกรดยังไม่สมบูรณ์
งานยังไม่ส่ง/รอตรวจคิด0ชั่วคราวในคะแนนรวม มีสถานะระหว่างเรียนจนข้อมูลครบ
จิตพิสัย/อื่น ๆ เป็นหมวดของงาน ไม่ใช่ระบบลงคะแนนพฤติกรรมรายวันอัตโนมัติ
ข้อสอบ EX_... ยังแปลงคะแนนดิบเป็นคะแนนเต็มของงานก่อนรวมในหมวด
คะแนนและเกรดยังซ่อนได้ตาม V57; API ไม่ส่งคะแนนหมวดให้เด็กเมื่อซ่อนผล

หน้าครู
มือถือ/iPad แนวตั้งแสดงการ์ดนักเรียน: คะแนนตัดเกรด/100 เกรด งานขาด รอตรวจ
จอกว้างแสดงตารางงานและคะแนน พร้อมแยกหัวคะแนนดิบและคะแนนตัดเกรด
แตะชื่อนักเรียน/การ์ดเพื่อดูคะแนน4หมวด ตรวจงานและให้คะแนนช่องใหญ่
ด้านบนมีการ์ดงานที่สั่ง ใช้แก้หมวด ประเภทส่ง คำชี้แจง และลิงก์ตัวอย่างงานเดิมได้
CSV เพิ่มคะแนนแยกหมวด (กรณีแบ่งหมวด)

หน้านักเรียน
แตะ “ยังไม่ส่ง / งานขาด” เพื่อดูเฉพาะงานที่ต้องส่ง
การ์ดแสดงชื่องาน หมวด คำชี้แจง วิธีส่ง คะแนนเต็ม กำหนดส่ง และสถานะเลยกำหนด
ถ้าครูแนบลิงก์ใบงาน/ตัวอย่าง มีปุ่มเปิดดูโจทย์ของครู (คนละส่วนกับช่องส่งคำตอบ)
ถ้าครูไม่ได้ให้โจทย์/ตัวอย่าง ระบบไม่สร้างภาพงานขึ้นเอง จะแสดงให้สอบถามครู
ครูใส่คำชี้แจงสั้น ๆ หรือแนบลิงก์ใบงานที่นักเรียนมีสิทธิ์เปิดได้ เพื่อให้รู้ว่าต้องทำงานไหน
ส่งรูปเท่านั้นมีเฉพาะช่องรูป/ตัวอย่างรูปที่เลือก/ปุ่มส่งรูป ไม่มี textarea หรือช่องส่งลิงก์
รูปแบบอื่นแสดงเฉพาะช่องที่อนุญาตเช่นเดิม พร้อมตรวจ backend
เมื่อเผยแพร่ผล เด็กเห็นคะแนนตัดเกรด/100 และเปิดดูคะแนนแยกหมวดได้
ตัวกรองงานไม่ล้างคำตอบหรือรูปที่ยังไม่ได้ส่ง
