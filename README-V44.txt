V44 – Exam Guard / Anti Split-Screen (best-effort)

เพิ่มในหน้าครูตอน “เผยแพร่เป็นข้อสอบออนไลน์”
- โหมดคุมสอบ / โหมดปกติ
- สุ่มลำดับคำถามต่อผู้เรียนแบบ deterministic
- สุ่มลำดับตัวเลือกต่อผู้เรียน
- ขอ Full Screen เมื่อเริ่มสอบ (ถ้าเบราว์เซอร์รองรับ)
- ตรวจออกจากหน้า, สลับ focus, ออกจาก Full Screen และ viewport หดผิดปกติที่อาจเกิดจาก Split Screen
- เลือกได้ว่าจะ “บันทึก+เตือน” หรือ “ส่งอัตโนมัติ” เมื่อเหตุการณ์เสี่ยงครบจำนวน
- ตารางผลสอบเปลี่ยนชื่อคอลัมน์เป็น “เหตุการณ์เสี่ยง”

หมายเหตุสำคัญ
- เว็บเบราว์เซอร์ไม่สามารถพิสูจน์การใช้ Split Screen/Google ได้ 100% ระบบนี้เป็น best-effort และควรใช้ข้อมูลเป็นสัญญาณให้ครูตรวจ
- การตรวจ resize มีการหน่วงและมี grace ตอนหมุนจอเพื่อลด false positive
- ไม่ต้องแก้ Apps Script สำหรับตัวเลือก V44 เพราะการตั้งค่าคุมสอบถูกแนบมากับลิงก์นักเรียน
