V39 Live Multi-Image Slide Studio
- แก้ข้อความและขนาดตัวอักษรแบบ Live ไม่ต้องกดอัปเดต
- แสดงสถานะ กำลังบันทึก / บันทึกแล้ว
- เปลี่ยนสไลด์เร็วขึ้น ไม่ render ทั้ง editor ทุกครั้งระหว่างพิมพ์
- เพิ่มรูปได้หลายรูปต่อสไลด์
- รูปแรกเป็นพื้นหลัง รูปถัดไปเป็น image layers
- แตะรูป layer แล้วลากตำแหน่งได้บน iPad/คอม
- ปรับซูม ตำแหน่ง และความกว้างรูปที่เลือกได้
- ลบเฉพาะรูปที่เลือกได้
- บีบอัดภาพก่อนบันทึกเพื่อลดอาการหน่วงและ localStorage เต็ม
- PDF รองรับหลายรูปผ่าน HTML render
- PowerPoint ส่งออกรูป layer เพิ่มเติมด้วย
